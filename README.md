I write backend code for a living and infrastructure because someone has to. Most of my day is PHP and Laravel — APIs, queues, database work, the parts nobody screenshots. The other part is Docker, Kubernetes and CI/CD pipelines, making sure what I write actually reaches production without someone SSH-ing into a server at midnight.

I like systems that are boring to operate. Clean deploys, readable logs, no surprises.

<br/>

### What I work with

**Backend** — PHP and Laravel every day. PostgreSQL and Redis behind them. I care about domain modelling and keeping business rules out of controllers.

**Frontend** — React with TypeScript, Tailwind for styling. Less of my time, but enough to ship a full product alone.

**Infrastructure** — Docker, Kubernetes, GitLab CI/CD, Linux. I build the pipelines that take code from a merge request to a running container.

### Currently learning

Kubernetes in depth — not just `kubectl apply`, but probes, resource limits, rolling updates and why they fail. Alongside it, software architecture: DDD, Clean Architecture, and the patterns that stop a codebase from rotting at year three.
